# Skill: open-design

Local-first, open-source Claude Design alternative from `nexu-io/open-design`
(56k stars). Native desktop app, 154 skills + 152 design systems. Tier 2.
Harvested skills (`od-*`) + the 152 design systems are in `champ-skills-bundle`.
The desktop app is installed separately.

## What it does
Artifact-first design: web, desktop, mobile prototypes, slides, images, videos,
HyperFrames. Sandboxed preview, HTML/PDF/PPTX/MP4 export. Drives Claude Code,
Codex, Cursor, Qwen, and 17+ CLIs. A skill is one folder with a SKILL.md the
app's daemon scans at startup.

## Why it fits [[Sreedeep Surapaneni|Sreedeep]]
The heavyweight design surface across all marketing/product output. Design
systems pair with the brand skills ([[Champions Group]], [[Lake B2B]],
[[Ampliz]]). Export to PPTX/MP4 covers decks and short social video.

## Install (app, macOS)
Latest release v0.9.0. Apple Silicon:
`open-design-0.9.0-mac-arm64.dmg` from
https://github.com/nexu-io/open-design/releases/latest
Open the dmg, drag to Applications. Intel Mac: use the `mac-x64.dmg`.
The app reads its own skills/design-systems internally; the bundle copies are a backup.
