# Full Trigger List: search-intent-audit

Trigger this skill on any of the following, and on close variants.

## Decline reports
- "traffic is declining" / "organic traffic dropped" / "traffic is tanking"
- "we lost rankings" / "why did we drop" / "positions are slipping"
- "Search Console looks bad" / "GSC is down" / "clicks are falling"
- "impressions are up but clicks are down"
- "we fell off page one"
- "traffic spiked down last week"
- "our blog traffic died"
- "the site has been sliding for months"

## Cause hunting
- "did the algorithm hit us" / "was this a core update"
- "are we losing traffic to AI" / "is ChatGPT taking our traffic"
- "did a competitor outrank us"
- "is this cannibalization"
- "did we accidentally noindex something"
- "why is only one folder affected"

## Intent questions
- "search intent audit" / "audit this page as a searcher"
- "does this page match search intent"
- "why isn't this page ranking even though it's well written"
- "is our content too fluffy"
- "why do people bounce from this page"
- "why isn't this page converting from search"

## Page quality and trust
- "does our site look AI generated"
- "why don't people trust our content"
- "our pages look generic"

## Implicit triggers (no keyword required)
- The user pastes a URL and says traffic or rankings are down.
- The user shares a Search Console screenshot, export, or chart.
- The user asks whether a decline is "normal".
- The user asks what to do about declining SEO before a board or client review.
- Any request to explain a drop before deciding on fixes.

## Do not trigger
- Pure keyword research with no decline context (use Ahrefs tools directly).
- A request to rank a page faster with no decline mentioned (use
  seo-rapid-ranker).
- A full technical crawl request with no traffic loss (use the Ahrefs site
  audit tools).
- Paid search or social traffic declines. This skill is organic search only.
