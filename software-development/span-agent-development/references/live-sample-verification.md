# Verify a live contact sample without confusing capture, retrieval and delivery

1. Read the deployed revision from the hosting control plane and compare it with the local checkout before attributing source behavior to production.
2. Trace the exact browser form endpoint through all callers. A queue insert proves capture only; require a provider transaction for retrieval and a mail receipt for delivery.
3. Read back the user's exact request privately and return only the request ID, scope and match result. Do not copy reply addresses, tokens or named contacts into public evidence.
4. Verify entitlement at every enrichment entrypoint, including generic model tools. A paid-account guard on one Connect tool does not protect a separately registered model tool.
5. Resolve technology customers to evidenced customer domains before buying people. A product vendor domain returns vendor employees, not the product's customer workforce. Aggregate counts cannot supply account membership.
6. Verify geography and other filters are actually applied, not merely echoed in a queued request or model answer.
7. Inspect browser-visible JSON, progress events, exports and bundles for supplier disclosure. Removing the provider label is insufficient when config, raw trace, errors or source fields still expose it. Keep restricted operator receipts intact.
8. Check current provider price and account balance before an approved paid test. Bound the complete billed page and every retry, not only displayed rows. Require atomic reservations and idempotency before concurrent product use.
9. Preserve a captured live aggregate answer for layout checks across themes and widths without regenerating it. Clearly label any later replay as captured evidence rather than a fresh live answer.
10. Treat full-page screenshots with sticky controls as ambiguous. Verify actual scrolled viewport captures before claiming permanent obstruction, and use DOM values rather than OCR for numerical claims.
11. Keep credentials injected in process memory. Do not persist authenticated browser storage, put credentials in command arguments, or print deployment variables.
